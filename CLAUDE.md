# Starcho JS

Aplicación Electron de notas locales.

- Electron 43.3.0 con Node.js 24.19.0.
- Express 5.2.1 y better-sqlite3 13.0.3.
- Renderer con ES modules vanilla y `contextBridge`.
- El único plugin de producto es `plugins/notes`.
- No añadir reproductores, descargas multimedia ni integraciones de YouTube.
